## 📖 The Story Behind It

I am currently learning web development at TechSphere Academy. 
A student in my community had exams during the course and missed 
the CSS lessons entirely. They had finished HTML but had not yet 
touched CSS.

Instead of pointing them to random YouTube videos or tutorials, 
I decided to build something structured, visual and interactive 
that they could follow at their own pace — and share it freely 
with anyone else in the same situation.

---

 🎯 Who Is This For?

This project is for anyone who:

- Is just starting out with CSS and doesn't know where to begin
- Missed lessons and is trying to catch up
- Feels like CSS concepts aren't clicking yet
- Wants a structured plan instead of jumping between random tutorials
- Is helping someone else learn and needs a resource to share

---

 📚 What It Covers

The plan is structured as a **5 week programme** with daily topics 
so it never feels overwhelming. Each week builds on the last.

| Week | Topic |
|------|-------|
| Week 1 | How CSS Works, Selectors & The Box Model |
| Week 2 | Display, Positioning & CSS Units |
| Week 3 | Flexbox — 1D Layouts |
| Week 4 | CSS Grid — 2D Layouts |
| Week 5 | Responsive Design & Finishing Touches |

---

 ✨ Features

- 📅 **5 Week structured plan** — daily topics, never overwhelming
- 🏆 **Challenges section** — 5 real coding exercises with hidden answers
- 📚 **Resources section** — clickable links to the best free tools
- 🧠 **Mindset section** — tips to stay consistent and avoid burnout
- 📱 **Fully responsive** — works on any device
- ⚡ **No sign up required** — open and start learning instantly
